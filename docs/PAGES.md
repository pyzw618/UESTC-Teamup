| 级别 | 页面 | 说明 |
|---|---|---|
| **公开** | 竞赛列表/详情、日历、用户名片 | 分享给人看不用先注册，利于收录；组队信息按下方分层 |

## 2. 竞赛雷达

### 2.1 首页 `/`　✅

登录与否都能看。第一屏回答"**现在有什么比赛我能参加**"。

| 区块 | 内容 | 数据来源 |
|---|---|---|
| Hero + 双入口 | 浏览竞赛 / 招募队友 | — |
| **近期报名截止** | 未来 30 天内报名截止的竞赛，按剩余天数升序 | `CompetitionEvent(nodeType=SIGNUP_END)` |
| **推免加分竞赛** | 只看能加分的比赛（核心刚需入口） | `Competition.isBonusEligible` |
| 热招队伍 | 招募中的帖子（登录可见，游客展示登录门） | `Team` |
| 按级别浏览 | 国际级 / 国家级 / 省级 / 校级 四色入口 + 计数 | `CompetitionLevel` |
| 本月节点 | 迷你日历预览 | `CompetitionEvent` |
| **适合你的竞赛**（需登录） | 按年级规则筛选的推荐位（非算法推荐） | `Competition` + `User.grade` |
| 系统公告弹窗 | 管理员发布的 active 公告，「今日不再弹出」 | `Announcement` |

### 2.2 竞赛列表 `/competitions`　✅

**筛选维度**（左侧栏 / 移动端抽屉）：
- 级别（四档，多选）
- **竞赛类别**（学科竞赛 / 文体竞赛，校教〔2026〕39号口径）
- 学科标签
- 面向年级 / 赛制
- **是否能加分**
- 状态（报名中 / 即将开始 / 已结束）
- **届次年份**（默认当前年份；`/api/competitions/years` 提供已收录届次）

**排序**：**认定文件顺序（默认，对齐《校教〔2026〕39号》文清单：学科竞赛在前、文体竞赛在后，新建竞赛排在末尾）** ｜ 报名截止临近 ｜ 最新收录 ｜ 难度 ｜ 热度

**列表项要素**：竞赛名 + 状态徽标（报名中/待定/已开赛）+ 级别色标 + **类别标签（学科=湛蓝 / 文体=银杏金）** + 学科标签 + 报名截止倒计时 + "N 支队伍正在招募"

**视图切换**：卡片视图 ｜ 表格视图

**列表状态恢复**：页码、搜索、筛选条件、排序和视图同步到 URL。进入竞赛详情后使用浏览器后退，或刷新列表页面时，恢复原列表状态；主动修改搜索 / 筛选 / 排序时回到第 1 页。缺省或不合法的页码按第 1 页处理。

### 2.3 竞赛详情 `/competitions/:id`　✅（V2 全新重写）

全站信息密度最高的页面，两个模块的交汇点。

| 区块 | 内容 |
|---|---|
| 头部 | 名称/别名/#code/届次、状态徽标（OPEN/UPCOMING/ENDED/UNKNOWN）、**竞赛类别标签**、级别色标、赛道数、**同 code 其他届次切换器**、关注、订阅 .ics、信息来源与反馈入口 |
| **报名倒计时大条** | 银杏黄渐变；未截止显示剩余天数，已截止显示"N 天前已截止" |
| 关键信息卡 | 主办方、官网、赛制（赛道级覆盖赛事级）、面向年级、难度/投入、赛程链 |
| **推免加分卡** | 是否计入 + 认定类别 + **BonusStandard 分值表（国家级 / 省级两行，按本竞赛类别展示对应分值）** + 特殊规则 + 「纠错」入口 |
| **赛程路线图** | 横向阶段卡（按 sequence 排序）+ 阶段类型徽标 + 国/省加分标 + 时间节点胶囊 + 每节点「纠错」；**多赛道时赛道切换**，当前阶段高亮 |
| **赛道总览** | 每赛道一张卡（阶段数、赛制、时间跨度），点击切换路线图 |
| 竞赛简介 | 管理员/种子维护 |
| **正在招募的队伍** | 本竞赛招募帖卡片 + "我也要发布组队"（游客见登录门） |
| 补充字段 | `CompetitionCustomField` 键值对（如 QQ 交流群） |
| 留言讨论 | `Comment(targetType=COMPETITION)` |
| 操作栏 | 关注 / 订阅 .ics（分享海报 P3） |

> 每个字段旁的「纠错」入口是人工维护模式的**事后纠错执行入口**，位置显眼但不干扰阅读。

### 2.4 竞赛日历 `/calendar`　✅

| 功能 | 说明 |

## 3. 队友招募（广告牌模式）

> 平台不做申请 / 邀请 / 审批 / 私聊；感兴趣的人登记「我想组队」意愿，或按队长公开的联系方式直接线下联系。

### 3.1 队伍列表 `/teams`　✅

**列表项要素**：竞赛名 + 状态徽章 + 目标 + **招募方向标签** + 队长 + 已有成员数（含队长）+ 意愿计数 + 招募截止倒计时

**筛选维度**：竞赛 ｜ 招募方向 ｜ 目标 ｜ 发布日期范围；排序：招募截止临近 ｜ 最新发布

**默认过滤**：**只显示 `RECRUITING` 且招募截止未过**的帖子；FULL / COMPETING / DISBANDED 不进入公共发现列表（避免僵尸帖）。

### 3.2 队伍详情 `/teams/:id`　✅

| 区块 | 内容 |
|---|---|
| 头部 | 竞赛卡（可跳转）、状态徽章、目标、招募截止倒计时 |
| 招募方向 | neededRoles 标签 |
| **已有成员情况** | rank / 年级 / 学院 / 介绍（登录可见） |
| 招募要求 | 队长填写的自由文本（登录可见） |
| 联系方式 | QQ / 微信 —— **仅队长 / 管理员 / 已登记组队意愿者可见**，未解锁不下发 |
| 操作 | **我想组队**（登记意愿，可撤销）／ 队长视角：编辑、改状态（RECRUITING/FULL/DISBANDED）、解散 |
| 评论区 | `Comment(targetType=TEAM)` 楼中楼 + 点赞 |

### 3.3 发布组队 `/teams/new`　✅

1. 选择竞赛（搜索选择器；**找不到可手动填写竞赛名，自动建档免审核即时发布**，并知会管理员）
2. 目标（单选）
3. 招募方向（多选标签，最多 10 个）
4. 已有成员情况（队长手填整表，纯展示）
5. 招募要求（文本域）
6. 计划招募人数（含自己，1-99）
7. 招募截止时间（**默认填竞赛报名截止时间**）
8. 联系方式（QQ / 微信至少一项）

> 除"选择竞赛 + 目标 + 联系方式"外，其余字段允许留空，降低发帖门槛。

## 7. 关键用户流程

### 7.1 核心闭环：从发现竞赛到线下组队

```
首页「近期报名截止」/ 日历 / 加分筛选
        ↓ 点进
   竞赛详情页（倒计时 + 赛程路线图 + 加分标准）
        ↓ 看到「正在招募的队伍」
   队伍列表（可按本竞赛过滤）
        ↓ 合适
   队伍详情 → 登记我想组队（解锁联系方式）或直接线下联系队长
        ↓
   队长收到聚合站内通知（计数更新不刷屏）
        ↓ 平台外沟通进队（平台不做审批）
   比赛节点开始后帖子自动置为「参赛中」
```

### 7.2 纠错流程

```
用户在竞赛详情页发现信息不对
        ↓ 点字段旁「纠错」
   CorrectionReport 入库，PENDING
        ↓ 进入 /admin/corrections
   管理员核对来源 → 采纳 / 驳回
        ↓ 采纳
   修正字段 + 记入 CompetitionRevision(origin=MANUAL)
```
