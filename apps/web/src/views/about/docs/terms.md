## 1. 协议的接受

使用 UESTC TeamUp（下称"本站"）即表示你已阅读并同意本协议。本站为在校学生自发搭建的公益项目，若你不同意本协议，请停止使用。

## 2. 服务性质

- 本站**免费**提供竞赛信息聚合与组队信息发布服务，按"现状"提供，不承诺服务不间断或无错误；
- 本站与电子科技大学官方部门无关，所有竞赛信息仅供参考，**报名等关键操作请以竞赛官方通知为准**。

## 3. 账号与身份

- 本站仅支持 `@std.uestc.edu.cn` 校园邮箱注册登录，请使用本人真实身份，不得冒用他人学号或邮箱；
- 请妥善保管账号与密码，账号下的操作视为本人行为。

## 4. 发布内容规范

通过本站发布组队帖、留言、纠错、反馈等内容时，你承诺：

- 信息真实、准确，不发布虚假招募或冒名信息；
- 不发布广告、代考代写、刷单等违法违规或与竞赛学习无关的内容；
- 不侵犯他人合法权益（包括但不限于名誉权、隐私权、知识产权）。

管理员有权对违规内容进行编辑或下架处理，情节严重的可封禁账号。

## 5. 联系方式与线下沟通

- 你在组队帖中主动填写的 QQ、微信等联系方式将**公开展示**，请自行评估并承担相应的隐私风险；
- 组队、合作等线下行为发生在同学之间，本站不参与、不担保，由此产生的纠纷与本站无关。

## 6. 免责声明

- 因自动化采集或人工维护导致的竞赛信息延迟、错漏，本站不承担责任；
- 因服务器故障、网络异常、不可抗力等导致服务中断或数据丢失，本站不承担责任。

## 7. 协议的变更

本站可能不定期更新本协议，更新后在本页面公布，继续使用视为接受更新后的协议。
