## 这是什么

**UESTC TeamUp（成电人的竞赛罗盘）** 是面向电子科技大学学生的竞赛信息聚合与组队平台：

- **竞赛雷达**：聚合竞赛信息与关键节点，不错过任何报名截止（DDL）；
- **竞赛日历**：全年节点一目了然，可一键订阅到手机日历；
- **队友招募**：像公告栏一样的组队广场，让志同道合的同学互相找到对方。

## 谁在做

本站由**两名计算机学院的本科生**利用课余时间搭建与维护，**纯公益性质**——不收费、无商业广告、不做任何数据买卖。本站与学校官方部门无关，数据仅供校内同学参考。

## 开源仓库

本站代码在 GitHub 开源：**[pyzw618/UESTC-Teamup](https://github.com/pyzw618/UESTC-Teamup)**

- 发现 bug 或有功能建议 → 欢迎提出 [Issue](https://github.com/pyzw618/UESTC-Teamup/issues)
- 想贡献代码 → 欢迎提交 [Pull Request](https://github.com/pyzw618/UESTC-Teamup/pulls)
- 竞赛信息有误 → 直接在对应竞赛详情页点「纠错」或「反馈信息问题」，处理更快

每一个 Issue 与 PR 都是对这个公益项目的支持，谢谢你的参与。
