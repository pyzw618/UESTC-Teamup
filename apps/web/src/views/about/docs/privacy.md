本站由学生公益团队运营，我们只收集维持功能所需的最少信息，不做任何商业化利用。

## 1. 我们收集的信息

| 信息 | 说明 | 用途 |
| --- | --- | --- |
| 校园邮箱 | 仅支持 `@std.uestc.edu.cn`，登录即注册 | 登录标识、DDL 邮件提醒 |
| 学号 | 从邮箱自动解析，仅登录同学可见 | 展示在个人名片 |
| 学院 / 年级 / 专业 / 昵称 | 注册后自愿填写 | 个人名片、按年级推荐竞赛 |
| 组队帖内容 | 含你主动填写的 QQ / 微信等联系方式 | 公开展示，供同学直接联系 |
| 留言 / 纠错 / 反馈 | 你主动提交的文字 | 站内展示与问题处理 |

## 2. 信息的存储

- 数据存储在本站部署服务器的数据库中，服务器与管理权限仅维护团队可控；
- 登录态通过 **HttpOnly Cookie** 维持；
- 本站不接入任何第三方广告、统计或追踪 SDK；
- 我们不会向任何第三方出售、出租或交换你的个人信息。

## 3. 你的控制权

- 个人资料、组队帖、留言均可随时在站内自行编辑或删除；
- 需要彻底注销账号、删除全部个人数据，可通过站内「功能问题反馈」或 GitHub 仓库联系我们处理。

## 4. 收集边界

本站面向在校大学生，不收集身份证号、住址、银行账户等敏感个人信息，也不面向 14 周岁以下儿童提供服务。

## 5. 政策变更

本政策如有更新，将在本页面公布并更新日期，继续使用视为知悉。

如有疑问：站内「功能问题反馈」，或 [GitHub 仓库](https://github.com/pyzw618/UESTC-Teamup)。
