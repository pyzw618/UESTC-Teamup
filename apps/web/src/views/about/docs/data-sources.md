## 1. 数据从哪来

本站竞赛信息主要来源于两类公开渠道：

- **各竞赛官方网站**：竞赛简章、报名通知、赛程安排等公开页面；
- **国内各高校发布的通知**：各高校竞赛组织部门公开发布的参赛通知（含校内选拔信息）。

## 2. 动态监听与更新

- 本站对上述来源采用**动态监听与更新**的方式：定期自动抓取来源站点的公开页面，解析出新增或变更的竞赛与时间节点后入库更新，持续跟踪、无需人工值守；
- 在自动采集之外，级别、推免加分等关键字段由人工比对官方文件后维护；
- 全站同学都可通过竞赛详情页的「纠错」入口参与维护，被采纳的纠错会记录为贡献者并锁定对应字段，防止被自动更新覆盖。

## 3. 准确性声明

- 自动化采集可能存在**延迟或错漏**，本站不保证信息与官方渠道完全同步；
- **报名截止、赛程安排等关键信息，请务必以竞赛官方网站通知为准**；
- 本站展示的摘要与链接均指向原发布渠道，相关信息的版权归属原发布单位。

## 4. 致来源站点

如果你是某来源站点的管理者，不希望本站收录贵站内容，或希望调整收录方式，请通过 GitHub 仓库 [pyzw618/UESTC-Teamup](https://github.com/pyzw618/UESTC-Teamup) 提 Issue 联系我们，我们会在核实后尽快移除或调整。
