第一条 服务定位

ShareLLM 提供包括但不限于以下服务：

  • 模型资源发布；
  • 模型渠道接入；
  • API 路由与请求转发；
  • 模型能力展示；
  • 调用计量；
  • 用户账户及额度管理；
  • 收益统计及辅助结算；
  • 其他与 AI 模型访问相关的技术服务。

平台中的模型资源可能由平台或第三方贡献者提供。

第二条 用户区域

根据平台运营规则，账户分为：

  • 中国大陆用户；
  • 非中国大陆用户。

默认情况下：

  • 使用 Google 登录注册的账户默认归类为非中国大陆用户；
  • 其他注册方式默认归类为中国大陆用户。

用户不得通过虚假信息、VPN、代理、借用账号或其他方式规避平台限制。

平台有权根据实际情况调整账户区域，并采取相应限制措施。

第三条 模型访问规则

平台根据模型来源及平台规则实施访问控制。

一般情况下：

  • 中国已备案模型按照平台规则开放；
  • 中国未备案模型及境外模型仅向符合平台规则的用户开放；
  • 中国大陆用户可以贡献资源，但不得使用平台限制访问的模型。

平台将在模型市场、路由中心、API 调用、Token 管理等环节实施自动访问控制。

用户及贡献者承诺：

用户不得利用平台从事违法犯罪、诈骗、网络攻击、侵犯知识产权、侵犯隐私、绕过计费、安全机制或其他违反法律法规及平台规则的行为。

用户因自身行为产生的一切法律责任，由用户自行承担。
